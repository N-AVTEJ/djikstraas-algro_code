How Dijkstra's Algorithm Works

Dynamic Weighted Shortest-Path Mathematical Engine

1

Initialize Distances

Set tentative distance to Origin = 0. All other nodes = ∞. Insert Origin into the Binary Min-Heap Priority Queue.

2

Greedy Minimum Selection

Extract unvisited intersection $u$ with lowest tentative cost from the Priority Queue in $O(\log V)$ time.

3

Dynamic Edge Relaxation

For each outgoing road segment $(u, v)$, compute dynamic traversal travel time:

$\text{Travel Time} = \frac{\text{Road Distance (m)}}{\text{Road Speed (m/s)}} + \text{Traffic Signal Delay (s)}$
  • Normal Road Speed = 45 km/h
  • Express Shortcut Speed = 65 km/h (with 35% time reduction)
  • Green Traffic Light = 0s delay
  • Yellow Traffic Light = +20s delay
  • Red Traffic Light = +60s delay
  • Blocked Road = ∞ (Impassable)

If $\text{cost}[u] + \text{weight}(u, v) < \text{cost}[v]$, update $\text{cost}[v]$ and record predecessor.

4

Backtrack Optimal Path & Reconstruct Geometry

Backtrack from Destination to Origin assembling the exact sequence of road geometry coordinates for Leaflet polyline rendering and smooth 60fps vehicle animation.

ℹ️ About CityNav Simulator

CityNav Simulator is a professional city navigation and shortest-path simulator demonstrating Dijkstra's Algorithm on a realistic road network in Central Hyderabad, India.

Key Architectural Highlights:

  • Reliable OpenStreetMap Basemap: Uses standard Leaflet OSM tiles with clean roads, parks, and Hussain Sagar water boundaries.
  • Clean Navigation First: Graph nodes and artificial lines are hidden by default; the user sees a real city map first.
  • Manual Pure JavaScript Dijkstra: Custom Binary Min-Heap Priority Queue implementation without any third-party routing API.
  • Dynamic Rerouting: Traffic lights cycle between Green, Yellow, and Red every 3 seconds, triggering instant dynamic recalculation.
  • Single Source of Truth: Road geometry coordinates drive both the displayed route polyline and the 60fps vehicle animation.
